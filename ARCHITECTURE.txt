C# ORM / Data Access Library — Minimal Architecture

USER
  -> Data Access Dashboard (frontend_csharp)
  -> Data Access API (backend_csharp)
  -> DataAccessService
  -> UnitOfWorkManager / ApplicationDbContext
  -> PartitionRouter
  -> StoreNode (1..N in-process)
  -> InMemoryStore (persistence/)
  -> ReplicationManager (distribution/)
  -> Response -> Frontend

CleanArchitecture concepts (Domain/Application/Infrastructure) are conceptual only.
